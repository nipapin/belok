# Пространство управляющего в master

Разделы: /admin/manager, /admin/reports, /admin/inventory, /admin/recipes, /admin/employees. Существующие разделы кухни и платежные интеграции сохранены.

Отчетность: произвольные даты по времени Калининграда, блюда, количество, сумма заказа, время, оплата, комментарии, CSV. В обзоре и отчете суммы заказов и успешных оплат отдельно по наличным и безналичным (CARD/SBP); бонусы и неизвестный тип отдельно. Отмененные исключены по умолчанию.

Пользователи показывают только USER, сотрудники — все остальные роли. Это фильтрация существующих аккаунтов, без изменения ролей и учетных записей.

Склад поддерживает инвентаризацию, приход, списание, выпуск заготовок и историю. Техкарты ограничивают доступность по текущему остатку; меню обновляется каждые 10 секунд. Автоматического списания продаж и резервирования пока нет. Позиции без ТТК остаются доступными по ручному признаку и отмечаются без расчета.

## Развертывание

Перед изменением схемы нужен pg_dump production. Только складские миграции: node --env-file=.env --env-file=.env.local --import tsx scripts/migrate-inventory.ts. Они идут в порядке зависимостей в одной транзакции; общие миграции запуска не требуют.

Проверки: TypeScript, ESLint измененных компонентов, 17 проверок расчетов и реального SQL на изолированной PostgreSQL, браузер desktop/mobile для отчетов, ТТК, стоп-листа и сотрудников, production build.
