# Проверка зависимостей 8 октября 2026

После `npm ci` на ветке `dev` npm сообщал о 17 уязвимых пакетах: 2 moderate, 14 high и 1 critical. Это результат аудита дерева зависимостей; сама установка завершилась успешно. Предыдущий коммит с вариантами товаров не менял зависимости или lock-файл.

## Выполненные обновления

- Next.js и eslint-config-next: 16.3.0 → 16.3.8. Диапазон `~16.3.8` сохраняет обновления в ветке 16.3.
- Sharp: 0.35.3 → 0.35.5.
- Совместимые исправления транзитивных зависимостей внесены в `package-lock.json` через обычный `npm audit fix`, без `--force`.
- Необязательный `postinstall` пакета `core-js-pure` явно запрещён через `allowScripts`. В проверенной версии скрипт печатает приглашение поддержать проект; полифиллы не требуют его выполнения.

## Оставшиеся предупреждения

Аудит после обновления сообщает о **6 high, 0 critical, 0 moderate**. Все шесть записей относятся к одной цепочке:

```text
@ducanh2912/next-pwa / eslint-config-next
  → fast-glob → micromatch → braces@3.0.3
```

В [GHSA-vfj7-8cjw-p6xm](https://github.com/advisories/GHSA-vfj7-8cjw-p6xm) исправленная версия `braces` пока отсутствует. Глубоко вложенные шаблоны могут привести к переполнению стека. В этом репозитории цепочка используется PWA-сборкой и линтером; код приложения не принимает пользовательские шаблоны для этих библиотек. Это ограничивает обнаруженный путь эксплуатации, но не отменяет предупреждение npm.

Предложенный `npm audit fix --force` понижает next-pwa до 6.1.0 и меняет совместимость инструментов. Такой обход не применялся. Заменять PWA-плагин или библиотеки поиска файлов следует отдельным проверяемым изменением, сохранив офлайн-страницу, кэширование и обновление service worker.

Сообщения `deprecated` для `inflight`, `glob@7`, `sourcemap-codec` и `source-map@0.8.0-beta.0` остаются в транзитивных зависимостях PWA/Workbox. Они не являются ошибкой установки. Обновления этих библиотек на несовместимые версии через глобальные overrides не применялись.

## Проверка и установка на dev

После обновления прошли чистая установка `npm ci`, шесть тестов расчёта вариантов и добавок, интеграционные проверки реальных API и браузера, регрессия перчиков, ESLint выбранных компонентов и сборка Next.js с проверкой TypeScript. Интеграционные проверки выполнялись на локальной временной схеме PostgreSQL; сборка использовала отдельный каталог `.next-test`.

Используйте зафиксированный lock-файл:

```sh
git switch dev
git pull --ff-only origin dev
npm ci
npm run build
```

`npm audit` продолжит возвращать ненулевой код из-за описанной цепочки. Предупреждения не скрываются. Команды развёртывания и миграции базы выполняются отдельно для окружения разработки; продакшн в этой работе не изменялся.
