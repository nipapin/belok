# Внутренние процессы dev — оплаты отключены

11 октября 2026. Локальная работа со складом и внутренними процессами.

- `BELOK_PAYMENTS_DISABLED=true` отключает Т-Банк, aQsi, отправку наличных заказов на кассу, чеки, синхронизацию каталога и обработчики очередей. В `next dev` оплаты отключены также по NODE_ENV.
- Локальный `.env`: выключатель включён, `AQSI_WORKER_ENABLED=false`. Секреты сохранены и не публикуются.
- Dev workflow, предпросмотр релиза и PM2-конфигурация содержат такой же выключатель. Изменения начнут действовать на сервере после отдельного выпуска dev.
- Платёжные действия API и callback Т-Банка возвращают 503; уведомления не подтверждаются как обработанные. Защита действует также на уровне библиотек, до запросов провайдерам.
- Очереди не удаляются. Их обработка и постановка новых фискальных задач отключены; позднее перед включением нужно отдельно проверить старые задания.
- Карта и СБП недоступны в интерфейсе. Внутренние заказы могут использовать CASH/BONUS, без передачи на кассу. Это обычные записи заказов и бонусного учёта, а не имитация подтверждённой банковской оплаты.
- Публичный флаг для интерфейса фиксируется при сборке; для включения нужен новый выпуск с выключателем false. Production в master не изменялся.

Проверка: `npm run test:payments-disabled` подставляет фиктивные ключи, перехватывает fetch и SQL; подтверждает отсутствие обращений к провайдерам и изменения очередей, блокировку callback и отсутствие запуска воркера.
