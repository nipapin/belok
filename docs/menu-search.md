# Поиск по желанию посетителя

В обычном поиске меню названия, категории и варианты фильтруются сразу.
Для запроса вроде «сытный обед» нужно нажать Enter или «Подобрать».
Примеры в пустом поиске запускают подбор одним нажатием.

`POST /api/products/search` принимает `{ "query": "сытный обед" }` (3–240 символов).
Сервер отправляет Claude текущий доступный каталог из активных категорий:
названия, описание, базовый состав, цены, известные КБЖУ, вес и варианты.
Модель ранжирует до 12 идентификаторов. Сервер проверяет их принадлежность каталогу
и повторно читает товары перед ответом, чтобы показать текущую цену и доступность.
Это список подходящих товаров, а не автоматически собранный заказ.

Настройки только на backend, без `NEXT_PUBLIC_`:

```dotenv
ANTHROPIC_BASE_URL=http://127.0.0.1:18765
ANTHROPIC_API_KEY=<токен нашего gateway>
ANTHROPIC_MODEL=claude-haiku-5-5
```

На сервере Белка локальный gateway доступен через настроенный VLESS-туннель.
Для dev значения сохранены в защищённом `.env.local` checkout dev.
Настройки production отдельно не меняются. Без этих переменных подбор возвращает
503, а фильтрация по названию продолжает работать.

Повторные одинаковые запросы с тем же каталогом кешируются на 5 минут в памяти
процесса; изменения цен, состава, вариантов или доступности меняют ключ кеша.
Одновременные одинаковые запросы используют один вызов модели.
Лимиты: 10 запросов в минуту на IP, до 4 одновременных обращений к модели,
20 секунд на вызов, максимум 2048 выходных токенов. Дополнительно действуют
лимиты и учёт стоимости gateway. Запросы посетителей не записываются в журнал.

У Haiku 5.5 установлен уровень рассуждения `output_config.effort: low`.
Лимит включает рассуждение и короткий JSON с выбранными товарами.
При смене модели нужно проверить поддержку этого параметра в
[документации Claude](https://platform.claude.com/docs/en/build-with-claude/prompt-engineering/prompting-claude-haiku-5-5).

Тесты: `npm run test:menu-search`. Проверяют доступность, чужие варианты и ID,
подмену полей, кеш, ошибки API, ограничение размера каталога и запросов.
